# AURA — SoundCloud на рабочем столе

Тёмный десктоп-плеер для Windows: настоящий SoundCloud, вход в аккаунт, синхронизированный текст песен и парящий мини-плеер, который почти растворяется в углу экрана и раскрывается при наведении.

![AURA](assets/icon-256.png)

## Что умеет

- **Настоящий SoundCloud** — поиск треков и плейлистов, прослушивание через официальный виджет, лайки, свои плейлисты и история.
- **Вход в аккаунт** — окно SoundCloud прямо внутри приложения. После входа доступны лайки и ваши плейлисты.
- **Мини-плеер** — отдельное окно поверх всех окон в центре верхней части экрана.
  - в покое почти невидим (прозрачность ~10 %);
  - при наведении плавно раскрывается в стеклянную панель с текстом и очередью;
  - кнопка-«булавка» оставляет панель раскрытой, кнопка «×» убирает её с экрана;
  - кнопка со стрелкой открывает основное окно AURA.
- **Синхронизированный текст** — караоке-подсветка строк (LRCLIB), клик по строке перематывает трек. Если текста нет — показывается очередь.
- **Очередь и плейлисты** — очередь в правой панели основного окна и во вкладке мини-плеера.
- **Глобальные горячие клавиши** — управление музыкой без переключения окон.
- **Трей** — закрытие окна сворачивает AURA в трей, музыка продолжает играть.

## Запуск

Нужен только установленный Electron (он уже лежит в `node_modules`).

1. Дважды щёлкните **`AURA.vbs`** — приложение откроется без чёрного окна консоли.
2. Или запустите **`start.bat`** (с консолью — удобно для диагностики).
3. Или из терминала:

```powershell
cd "C:\Users\Dmitriy\Documents\Проект по умолчанию"
.\node_modules\electron\dist\electron.exe .
```

Если папка `node_modules` отсутствует:

```powershell
npm install
```

> В этой сборке Node.js и Electron уже подготовлены локально (`tools\node`, `node_modules\electron`), интернет нужен только для самого SoundCloud и текстов.

## Установщик для Windows

Собрать обычный `.exe`-установщик (NSIS: выбор папки установки, ярлыки на рабочем столе и в меню «Пуск»):

```powershell
npm run build:win
```

Готовый файл: `dist\AURA Setup 1.0.0.exe`.

## Android

В папке `android/` лежит нативная версия для телефона (Kotlin + Jetpack Compose + Media3).
Мини-плеер там — это `MediaStyle`-уведомление в шторке: карточка с обложкой и
кнопками «назад / играть-пауза / вперёд».

```powershell
powershell -ExecutionPolicy Bypass -File android\build-apk.ps1
```

Готовый APK: `AURA-android.apk`. Подробности — `android/README.md`.

## Вход в SoundCloud

1. Нажмите **«Войти»** в правом верхнем углу.
2. В отдельном окне войдите в свой аккаунт SoundCloud (или создайте новый).
3. Окно закроется само, а в AURA появятся ваши лайки и плейлисты.

Если SoundCloud показывает «браузер не защищён» — это ограничение Google-входа
внутри встроенного окна. Войдите по **email и паролю** прямо на странице
SoundCloud: такой вход работает и в приложении.

Токен хранится только в файле настроек приложения на этом компьютере. «Выйти» удаляет его.

## Мини-плеер

| Действие | Что происходит |
| --- | --- |
| Навести курсор на полоску | Панель раскрывается |
| Увести курсор | Сворачивается обратно (если не закреплена) |
| Булавка в панели | Оставить раскрытой |
| «×» в панели | Убрать мини-плеер с экрана |
| Вкладка «Текст» | Синхронизированный текст, клик по строке — перемотка |
| Вкладка «Очередь» | Текущая очередь, клик по треку — воспроизведение |
| Стрелка / двойной клик по полоске | Открыть основное окно AURA |

Положение мини-плеера (сверху или снизу по центру) переключается в
**Настройках** → «Положение мини-плеера» и в меню трея. По умолчанию — снизу по центру.

## Горячие клавиши

| Комбинация | Действие |
| --- | --- |
| `Ctrl + Alt + Space` | Играть / пауза |
| `Ctrl + Alt + N` | Следующий трек |
| `Ctrl + Alt + P` | Предыдущий трек |
| `Ctrl + Alt + M` | Показать / скрыть мини-плеер |
| `Ctrl + K` | Поиск |
| `Space` | Играть / пауза (когда окно в фокусе) |
| `Esc` | Закрыть панель / снять фокус |

## Устройство

```
main.js              Electron: окна, трей, вход, IPC, мини-плеер
preload.js           безопасный мост window.aura
src/sc.js            SoundCloud API, авторизация, LRCLIB, нормализация
src/store.js         настройки в userData/aura-config.json
index.html           основное окно
overlay.html         мини-плеер
css/app.css          стили основного окна
css/overlay.css      стили мини-плеера
js/core.js           состояние, плеер-виджет, очередь, текст
js/ui-views.js       главная, поиск, лайки, плейлисты
js/ui-player.js      нижняя панель, правая панель, настройки
js/app.js            запуск, события, горячие клавиши
js/overlay.js        логика мини-плеера
js/demo-data.js      демо-треки для режима без Electron
```

Приложение использует публичный `client_id` SoundCloud и официальный iframe-виджет для воспроизведения. Это неофициальный клиент; музыка принадлежит авторам и SoundCloud.

## Если что-то не работает

- **Нет звука** — проверьте, что трек не защищён правообладателем (виджет покажет ошибку), и громкость в правом нижнем углу плеера.
- **Не находится текст** — LRCLIB не все треки; попробуйте другой.
- **Не входит в аккаунт** — SoundCloud может требовать капчу; пройдите её в открывшемся окне. Если окно закрылось, нажмите «Войти» ещё раз.
- **Мини-плеер не появляется** — включите его в настройках или в трее («Мини-плеер на экране»).
- **Порт/запуск** — приложение уже собрано; пересборка не требуется.
